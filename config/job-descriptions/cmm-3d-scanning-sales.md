# 职位描述 (Position Description)

负责三坐标测量机（CMM）与三维扫描/光学测量设备的销售工作，开拓制造业客户，提供接触式测量与光学扫描综合方案。

# 职位要求 (Job Requirements)

机电中专或以上学历，有一年以上三坐标、三维扫描、计量仪器或精密测量设备销售经验，或有相关应用/售后经验欲从事销售。

# 必要条件 (Required Criteria)

- 机电中专及以上学历
- 具备销售经验或测量应用/售后转销售意向
- 熟悉三坐标测量机、三维扫描或计量仪器行业术语

# 优先条件 (Preferred Criteria)

- 同时具备三坐标测量与三维扫描/光学测量销售或应用背景
- 有海克斯康、蔡司、三丰、法如、中图仪器、先临三维、思看科技、形创、GOM 等品牌经验
- 熟悉 PC-DMIS / CALYPSO / Geomagic / PolyWorks / GOM Inspect 等测量或逆向软件
- 有华南（东莞/深圳）制造业客户资源

# 关键词 (Keywords)

三坐标, 3D扫描, 三维扫描, 三坐标测量机, CMM, 3D扫描仪, ATOS, 光学测量, 计量, 逆向工程, 海克斯康, 蔡司
