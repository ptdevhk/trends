# 职位描述 (Position Description)

负责三坐标测量机（CMM）及相关计量/检测设备的销售工作，开拓制造业客户，维护客户关系。

# 职位要求 (Job Requirements)

机电中专或以上学历，有一年以上三坐标、计量仪器或精密测量设备销售经验，或有相关应用/售后经验欲从事销售。

# 必要条件 (Required Criteria)

- 机电中专及以上学历
- 具备销售经验或测量应用/售后转销售意向
- 熟悉三坐标测量机或计量仪器行业术语

# 优先条件 (Preferred Criteria)

- 有海克斯康、蔡司、三丰、法如、中图仪器等品牌销售经验
- 熟悉 PC-DMIS / CALYPSO / MCOSMOS 等测量软件
- 有华南（东莞/深圳）制造业客户资源

# 关键词 (Keywords)

三坐标, 三坐标测量机, CMM, 计量, 测量机, PC-DMIS, 海克斯康, 蔡司, 三丰, 精密测量
