组件清单

  • TopBar — 吸顶，品牌 + 实时搜索 + 中英切换 + 规范入口
  • HeroReadout — 仪表式读数：大数字 + 涨跌徽章 + 光栅走势图
  • DayStrip — 7 天日报切换，当前日琥珀高亮
  • SectionHeader — 序号 + 主标题 + 英文副标 + 说明
  • FilterChips — 胶囊筛选（全部 / 高热度 / 新增）
  • OpportunityCard — 封面占位 + 热/涨徽章 + 标题 + 标签 + 迷你走势
  • FeaturedCard（精选） — 抖音式双栏卡片：封面 + 精选角标 + 热度角标 + 标题 + 来源/涨幅 meta
  • TrendingRow — 排名 + 类型徽章 + 标题 + 标签 + 热/涨数值
  • StoryItem — 序号 + 标题，双列栅格
  • Badge / Chip / Sparkline — 通用原子组件
  • Toast / SpecDrawer — 反馈与规范面板
